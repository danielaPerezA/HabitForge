# Habit Tracker Gym App

## Descripción
Habit Tracker Gym App es una aplicación móvil diseñada para ayudar a los usuarios a crear y mantener hábitos de entrenamiento en gimnasio. La aplicación permite registrar sesiones de entrenamiento, establecer metas personalizadas y hacer seguimiento del progreso mediante un sistema de rachas y estadísticas visuales.

## Objetivo
Desarrollar una aplicación que ayude a los usuarios a construir disciplina y constancia en el entrenamiento físico mediante el seguimiento de actividades, monitoreo de metas y motivación basada en rachas.

## Funcionalidades
- Registro de sesiones de entrenamiento  
- Historial de entrenamientos  
- Creación de metas personalizadas de asistencia  
- Seguimiento del progreso  
- Sistema de rachas de constancia  
- Dashboard con estadísticas de hábitos  
- Notificaciones relacionadas con metas y rachas  

## Usuarios Objetivo
Personas interesadas en mejorar su constancia en el gimnasio y desarrollar hábitos fitness sostenibles.

## Alcance del Proyecto
La aplicación proporcionará herramientas para registrar entrenamientos, monitorear el progreso y fomentar la disciplina mediante seguimiento visual y gamificado de hábitos.
